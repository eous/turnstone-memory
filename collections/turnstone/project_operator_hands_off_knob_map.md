**Approval gate order** (`SessionUIBase.approve_tools`, session_ui_base.py:1480 — shared by WebUI AND ConsoleCoordinatorUI): (1) admin tool policies (fnmatch on `approval_label` || `func_name`; allow→auto, deny→block, ask/None→fall through) → (2) `auto_approve_tools` (skill allowed_tools / Approve+Always) → (3) blanket `ws.ui.auto_approve` → (4) smart approvals → (5) human, `ATTENTION` state. Because the body is shared, a **policy `allow` rule DOES clear coordinator `spawn_workstream`/`spawn_batch` prompts** (labels are exactly those strings, session.py:11633/11849). skills-load label is `skills__load__<name>__<digest>` → pattern `skills__load__*`. Policies hot-reload (TTL cache + invalidate); this is the reliable no-restart lever.

**`tools.skip_permissions` is a node-STARTUP snapshot** (`app.state.skip_permissions`, server.py ~4818/5504; applied to new interactive ws at create ~2297). Coordinator sessions never get blanket auto_approve, and `CoordinatorClient.spawn` passes no auto_approve — children get it only from the worker node's startup snapshot (or scheduler-task body / skill auto_approve). **The maintainer's framing (2026-07-16): skip_permissions is a LEGACY hack, likely to be dropped in favor of tool policies — recommendations must LEAD with tool policies + smart approvals, never with skip_permissions.** Hands-off recipe: policy `allow` rules (incl. spawn_*/send, hot-reload, cover coordinators) + `judge.smart_approvals=true` for the judged long tail + trust-send toggle; skip_permissions only as a stopgap with the restart caveat. Residual human gates: `__budget_override__`, deny/critical, judge review/low-conf/timeout under smart approvals, MCP consent.

One active skill at a time; defaults concatenate only when no named skill; `skills(find/load)` + `activation="search"` catalog = model-driven switching; `/skill <name>` = manual. **RULING (the maintainer asked, 2026-07-16): swap-removal is NOT a HYPOTHESIS.md violation** — deterministic gated state change, current value lowered verbatim, old body re-derivable (DB row + re-load = the "originals kept, context is a cache" shape of the derived-state appendix entry); dropping the old body from c is a C1 π-sufficiency question (empirical), same family the doc blesses for compaction.
