Follow-up to [[project_projects_feature_design]]: first shared-workstream pass exposed three gaps; all three built on branch **feat/project-sharing-gaps** (2026-07-01, originally 4 commits on top of a7cab83d, then a 5th post-review commit — see below). **Shipped as PR #743, 2026-07-02.** 4th commit (9e05441a) = full-suite sweep: `ws_visible` type-guards non-str project ids (test doubles ≠ private), HTTP send binds acting user via getattr-guarded `bind_acting_user` in the fresh-turn closure NOT a send() kwarg (per-kind session stubs have explicit send signatures), row-shape contract tests (interactive + coord twins) include `project_id`.

1. **MCP oauth_user creds follow the acting user** (688b9eb2): `_mcp_user_id` (persisted ws creator, set once at construction) stays the fallback; new sticky `_acting_user_id` bound by authenticated send/retry (`bind_acting_user`, session.py). All dispatch + catalog + visibility sites read `_mcp_effective_user_id`; rebind swaps user-scoped MCP listeners (identity = `(user_id, callback)` pair, tracked in `_mcp_listener_user_id` — close() must use it), primes new user's pools, rebuilds tool lists. **Prepared tool items pin `mcp_user_id` at prepare time** so pending approvals execute as the requester. Interjections (`queue_message`) deliberately do NOT rebind mid-turn. Not threaded: channels (Discord/Slack) sends, web_search-backed MCP (pre-existing no-user), coordinator children (inherit coord owner).

2. **Private-project workstream visibility** (fcf0b18b): `WorkstreamProjectVisibility` (core/auth.py) — private → project owner/member OR ws creator OR service scope OR `admin.cluster.inspect`; public/dangling/no-project unchanged. **Membership itself is the grant — deliberately NOT `project.read`-gated** (that RBAC cap guards the management API; members without it must not lose their workstreams). Enforced at: saved list (`_collect_saved_rows`; `list_workstreams_with_history` grew tail-appended `project_id, user_id` — 17-tuple now), active list, node dashboard, console cluster list (collector `row_filter` pre-pagination), node detail, console tier-1 SSE (per-connection snapshot filter + hidden-set for sparse events; membership changes apply on reconnect), row access via `resolve_workstream_owner` → 403 (covers all interactive verbs via tenant_check; console coord lane stays admin.coordinator-gated), create-time `ensure_project_attachable` (unknown pid=400, private non-member=403; re-checks parent-inherited pid).

3. **Project column + resources shelf** (300b6da9): `SavedColumns.project()` on both saved tables (async cache → `onProjectsChange` re-render; filter haystack includes project name; headless-verified). `GET /v1/api/projects/{id}/resources` (project.read + ACL) → workstreams + attachments + memory_count; new storage queries `list_workstreams_for_project` (first user of idx_workstreams_project) + `list_project_attachments` (conversations ref-list walk, metadata-only, first-referencing ws per blob). Admin shelf rows expandable (clone of Users-tab OIDC panel, `.proj-detail-*` CSS); attachment links route via console node proxy `/node/{nid}/v1/api/...`.
