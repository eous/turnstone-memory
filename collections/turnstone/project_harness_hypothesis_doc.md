Design rules now in the doc, with direct Turnstone bearing:
1. **Narrow-only rule**: learned checks (LLM judges) may only NARROW the deterministic admissible set, never widen it; only the **trusted principal** (user approval = γ-authorized action into Q_E, sole e-class ρ may fold into control coordinates) widens authorization. Judge-as-approver rests the certified floor on γ_det alone → why [[project_smart_approvals]] default-off was right. Control-determining splits into TWO RANKS: **authority** (grants/scopes/budgets — only the top writer WIDENS it; budgets deplete and scopes narrow without the principal) vs **plan** (middle rank by a STANDING ENDORSEMENT — the plant's output is no more trusted than the least-trusted content of c, and ρ's gated fold of y raises it to plan rank at every step; the model rewrites it, never widens authority; CaMeL = pin plan to top-derived rank before untrusted reads → control-flow integrity there, with argument integrity resting on the gate's data-flow policies and side channels left open; interactive replanning pays the priced adversarial cost). **Rank-neutrality corollary** (added after [[project_plan_agent_removed]]): a planner/critic that reads the same mixed-provenance context as the model and only writes middle-rank state changes NO guarantee — priced by evals alone (one confined to top-rank inputs is the pinning move, not neutral); the certificate prices only rank crossings, gates, and Π.
2. **Minimal deterministic core** = {γ, ρ, H} **plus π's never-lower filter** (deterministic redaction keeping credentials/other-principals' data out of C — exfiltration is cut at either chokepoint: never lowered at π, or never emitted at γ); only π's *selection* may be learned (reranker, compaction), costing semantic adequacy — legitimizes rerank-in-π.
3. **Gate TOCTOU**: γ's guarantee is per-snapshot; cross-run shared authorization state (coordinator-tree budgets/quotas/locks) needs ledger serialization — the per-run certificate is silent about it.
4. **Composition law** (four correspondences): child harness = Q_E component from parent; parent consumes child budget bound E[τ_H] + child ledger-as-effect-record + child refusals-as-partial-failures + **spawn grant = Π-restriction** (grant bounds what child *could* reach, ledger reports what *happened* — safety composes without reading the child's gate); opaque bash = un-annotated child.

Claims numbered C1–C7 (C5 an open question, not yet a statement; C8 deleted 2026-11-09 — [[project_harness_interlingua_frontier]]), each with a test, and the handles are of four kinds, so "falsifier" fits only some: framings and points of logic (judged by use or proof), conformance properties of an implementation (one violation refutes), empirical predictions (data refutes), and the open question. The π-sufficiency probe = compaction test; the working-set probe is a MEASUREMENT of C6's counting fact, run on families with a proven lower bound on how much input must be read or moved, beside a control family — not a falsifier.

Appendix worked instances (expanded 2026-07-01): cancellation · **resume** (journal-before-dispatch WAL forced by unknown≠none; action_id = idempotency key; crash ≠ halt, re-enter T at durable s — bears on CLI resume() gap) · gate placement (+ narrow-only rule, **ambient authority**: per-action capability, enforcement = Π-shaping, TOCTOU) · **batch gate** (individually admissible ∦ jointly admissible — exfil pairs, summed budgets; authorize the set atomically) · effect records (+`none` status) · **derived/durable state** (provenance closure, the doc's "closure rule", formerly "meet rule": a transformation's output — the plant's included — is no more trusted than its least-trusted input and no less secret than its most-secret input — compaction summaries are data, plan crosses verbatim or re-confirmed; memory labels persist across sessions; MCP tool catalogs = data at s₀; destructive compaction = gated irreversible self-effect, keep originals content-addressed) · composition (+ **delegation**: authority attenuates monotonically down the tree; parent answers only from held grants else route to root; autonomous = authorization frozen at launch) · **daemons** (added PR #810: recurrent harness — excursion = one absorbing run with ready set 𝓡 playing halt; renewal-reward lifts per-run certificates to long-run rates when the ready set is a genuine regeneration point (sufficient, not "exactly when"); what accumulates breaks regeneration → the closure rule must hold ACROSS cycles, renewal events — owner re-confirm, audit, cred rotation, verified re-compaction — reset the carried state the hazard depends on, not the decay: a daemon can state a hazard rate or survival over a declared horizon, never (q>0) survival without one; per-cycle hazard compounds (1-q)^N; owner contact = authority renewal point, stale grant vs fresh world = cycle-scale TOCTOU; learned-veto escape degrades to always-enabled safe halt when principal unreachable).
7. **C4 class-level impossibility (theorem — Turing; no new citation):** the unrestricted harness class contains instances that simulate arbitrary programs — fixed-output model + ρ advancing an externally stored program one instruction per step + decidable halt test ⇒ p_succ is that program's halting indicator — so no sound, complete, always-terminating decision procedure resolves eventual success for every harness in the class. A mandatory budget defines a restricted SUBCLASS the reduction cannot inhabit and certifies RAW termination only (a counter bounds outer transitions, assuming each transition — model call, tool execution, controller computation — completes); it says nothing about correct or safe completion. A certificate for an unbudgeted harness may be discovered afterward (ranking-function synthesis) but is not guaranteed. **Refuted in review — do not reintroduce:** "universality lives in the shell" (universality is a property of the composed system; locating the memory does not locate computational responsibility); "finite plant ⇒ computable outer V*" (computability of the inner kernel does not transfer to the outer functional — the reduction above is the counterexample); "open-loop ⇒ nothing to certify, closed-loop ⇒ observable" (feedback ≠ observability). The inner process is finite because the Stop cap forces τ finite, not because of fixed L alone (b_t is untruncated).
8. **C5 specification debt:** C5 charges for oracle access — absolute description length with W counted; a short evaluator that calls M_W is not a compressed certificate (workspace bounds on an evaluator ≠ description-length bounds on a certificate); the compression-search falsifier requires a SELF-CONTAINED V̂. And C5 has not named its target: the full specification is target object & system, task domain, representation language, precision & tolerance, and access to W / tools / other oracles with their cost — then, separately, computability of the target under those assumptions and the size claim. The inner kernel's output law or expected generation length is NOT the target (a model forced to emit exactly k tokens has expected length k; computability ⇏ incompressibility). Relocating C5 to the inner kernel is a change of conjecture, not a consequence — refused in review.
9. **Reconstruction-consistency check (Resume entry; #1311's foundation):** the context lowered on a reopen is the harness's claim about its own past, and nothing checks it — a reopen that rebuilds a different prefix from the same durable s (fresh temp path per load, live-read skill file, message swapped ahead of history) silently rewrites what the plant believes happened. Remedy: hash chain over RETAINED context records (record definition, canonicalization version, checkpoint, comparison point fixed in advance), reopen recomputes and compares heads. Stated at true strength: a mismatch = reconstruction disagrees with the commitment under the same rules — a LEAD for the C1 state-ablation falsifier and the C2 determinism audit, not either mechanized; a digest alone locates nothing; a MATCH cannot establish completeness; the check sees only the controller's own side of its channels; the reference head must sit outside the authority that can rewrite the history. Deliberate changes (compaction, skill switch, model change, rewind) append entries committing to the old head; rewind is an entry; forks anchor in the source head; the data-vs-control decision needs trusted field labels + entry-level comparison. Homed as a C1/C2 question, NOT attestation.
10. **Plant channel as a trust boundary (The limit, beside provenance isolation):** a remote M_W is reached through intermediaries; any with plaintext access (TLS-terminating proxy = a router) is a party to the loop, and the displayed T cannot express it — the model step is identity on w, so a passive copy of c is a world write with no leg in T. Whether that matters is a PROPERTY question, not a remoteness one; wherever disclosure of c can reach B the extension is a world-touching plant call M~:(c,w)⇝(y,w') with Q_E reading the w' it left, M_W⊗id_w being what a trust assumption collapses it to. Robust quantity = SUPREMUM OF EXPECTATIONS over (α,β), β ranging over a CAPABILITY-BOUNDED admissible class (traffic observed, messages alterable, state retained, disclosure effects) — never arbitrary kernels (an unconstrained β voids the question); A_out∘M_W∘A_in is one admissible shape; whether model substitution is admitted is the class's to say; retained intermediary state lives in latent w, separate from the strategic choice that makes it a game. Confidentiality labels are per recipient (filter's clearance test reads endpoint/route config already in s); chokepoint condition = every plaintext recipient of c accounted for and permitted; a credential in c was ALREADY a never-lower violation — bind-at-dispatch is that rule's implementation ("the plant proposes which, never with what"). What the channel specifically defeats: PLAN COHERENCE AS INDEPENDENT EVIDENCE OF INTENT (structural intent checks against a plan the intermediary may have written via the licensed middle-rank fold). Fail-closed unchanged; learned checks bounded to no authority beyond the deterministic baseline (a forged APPROVAL can suppress a veto the honest judge would have issued — not "only denials"); an independently enforced invariant survives arbitrary forgery; the surviving guarantees are those re-proven under the admitted hostile inputs — a fact about the implementation, not the signature. Two scopes: (a) authenticated channel — responses bound to request AND model identity, plaintext recipients of c known and within the filter's clearance set (signing alone reaches none of the exfiltration half of B); (b) the bounded hostile class admitted into Π and the certificate re-established — a recheck, not a forfeit. Model substitution behind a fixed name = a C1 violation the version coordinate cannot register without an identity-binding envelope. δ calibrated through a stable intermediary measures the routed system; a CHANGE in its behavior is the silent version bump. **Refuted in review — do not reintroduce:** "only the authority rank survives" / "a safety certificate exists exactly when the grant alone excludes B" (counterexample: two grantable bits, gate holds x+y≤1 against any forgery — safety from the check, not the grant); "every remote-plant deployment violates realizability"; "a chokepoint only when no party but the plant reads c"; β over "arbitrary kernels"; "expectation becomes a sup over response laws"; "a router is a version bump"; hidden memory ⇒ Markov game (memory can live in w; strategy makes the game).
